# Volleyball Motion Tracking and Feature Extraction
This repository contains a project designed to use motion tracking for volleyball matches and predict which individual is set. 
The dataset for this project can be found here: https://github.com/shukkkur/VolleyVision/tree/main?tab=readme-ov-file.

To run this project, the data had to be downloaded as well as the Yolo v8 model, which is a type of CNN designed to quickly analyze image data. 
This project was an experiment on motion tracking and pose detection. While the current status of the model only predicts which individual was set,
I hope to improve upon it in the future and maybe add full motion tracking at some point. 

I mounted my drive to run the notebook, so you will be unable to simply download and run the notebook.
